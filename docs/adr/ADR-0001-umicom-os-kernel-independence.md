# ADR-0001: Umicom OS is Kernel-Independent

- Status: Accepted
- Date: 1 October 2026
- Owner: Sammy Hegab, Umicom Foundation
- Extends: Umicom OS architecture decision dated 2 September 2026

## Decision

Umicom OS is a kernel-independent operating-system platform.

GNU Linux-libre is the current production kernel implementation.

FreeBSD is the primary portability/server-appliance evaluation target.

Umicom Kernel is the original native implementation under development.

Changing the production default requires a separate decision and promotion evidence.
