# Umicom Kernel artwork

These files are complete canonical copies of Umicom Framework's resources/brand assets. Use the SVG wordmark in light guide surfaces, the SVG icon for scalable application identity, and the ICO file for Windows resources. Preserve the artwork's aspect ratio and transparent background.

The source of truth remains Framework. When an approved master changes, compare and update these copies together with their consumers; do not redraw the mark. Fonts belong to the host renderer or application appearance profile. Documentation uses the existing Umicom Segoe UI family and Cascadia Code/Consolas stacks where the renderer supports styles; this folder does not redistribute font software.

The freestanding Kernel has no Windows icon loader or browser favicon service. Including assets in this repository does not claim that a boot console renders them. Hosted learning executables obtain their resources through Framework's application-branding helper.
